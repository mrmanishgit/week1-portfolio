# Personal Portfolio Website

## 📌 Project Description
This is a responsive personal portfolio website showcasing my skills, projects, and contact information. The website is built using HTML5, CSS3, and basic JavaScript following modern web design principles.

---

## 🚀 Features
- Responsive design (mobile, tablet, desktop)
- Semantic HTML5 structure
- CSS Grid and Flexbox layouts
- Smooth navigation
- Contact form with validation
- Hover effects and animations
- Background images for each section

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## ⚙️ Setup Instructions
1. Download or clone the repository
2. Open the folder in VS Code
3. Open index.html
4. Run using Live Server
